# Ros2 Robot Arm Study Using Koch v1.1 Follower
The following repository has the source, resources, and instructions for building a robotic arm based on a modified Koch V1.1 physical design using powered by ROS2. The goal is to explore both the software and hardware used in robotic arm development. This includes:
 - Fabrication and/or purchase, and assembly of robotic parts (brackets, Dynamixel servos, and related circuit boards)
 - Testing and tuning of the physical robot
 - Refinement of ROS2-based software to support various actions of the robotic arm
